# Structure & Reactivity Workbook

Interactive IB Chemistry (2025 syllabus) revision workbook covering every Structure and Reactivity topic: notes, practice questions, HL past-paper questions, the data booklet and a periodic table.

## Files
- `index.html` – the whole app (open this)
- `lessons/` – interactive lesson notes for each topic
- `pp/` – Paper 1 and Paper 2 past-paper questions for each topic
- `r1extra.json` – extra assessment and textbook material for R1.1 and R1.2

## Publishing with GitHub Pages
Settings → Pages → Source: **Deploy from a branch** → Branch: `main`, folder `/ (root)` → Save.
The site appears at `https://<your-username>.github.io/<repo-name>/` after a minute or two.

## Saving progress
On GitHub Pages, students' answers are saved in their own browser only. They can use **My progress → Copy summary** to send results to their teacher. The class results view and cloud saving only work in the Claude-hosted version.
